# FishingHelper · 艾泽拉斯钓鱼助手

Windows 桌面应用，源码入口为 `app.py`。旧脚本和历史设置不受影响。公开仓库不包含个人声道配置、游戏录音模板或构建产物。

## 首次使用

1. 打开 exe。软件会枚举系统输入设备并标出是否检测到 **VB-CABLE**。若未检测到，点“下载 VB-CABLE Pack45”会从[厂商官方下载页](https://vb-audio.com/Cable/)下载当前提供的 `VBCABLE_Driver_Pack45.zip`；解压后以管理员身份运行对应安装程序，重启系统，再按“刷新声道”。也可以直接改用实际输入设备。
2. 游戏内将声音输出到 `CABLE Input`，软件选择 `CABLE Output` 作为输入。后台模式下还要开启游戏的“背景声音”。首次使用时，点击“选择鱼漂声音”，指定自己录制的 `.ogg` 或 `.wav` 模板。
3. 点击界面里的键位按钮并按下想用的按键。原默认值为小键盘 1/2/3 和 F8/F9；转向键可右键点击按钮清空。游戏内建立宏：插件启动宏 `/fh start`，战斗宏使用你自己角色的一键战斗宏。将它们绑定到软件所填按键。
4. 若要读取游戏确认的渔获，点“自动查找”或手动选择包含 `_retail_` 的 World of Warcraft 根目录，再点“安装插件”。游戏已运行时用 `/reload` 加载插件。插件平时只注册命令；按启动宏或输入 `/fh start` 后才记录。
5. 点击“开始钓鱼”。软件的“抛竿指令”和“收竿指令”只是按键计数；游戏记录中的成功出杆、失败出杆和渔获由插件事件决定。

## 功能边界

- 右键鱼漂交互暂未实现，当前仍使用抛竿键和收竿交互键。
- 插件监听 `UNIT_SPELLCAST_*`、`UI_ERROR_MESSAGE`、`CHAT_MSG_LOOT` 和进出战斗事件。出杆“水太浅”“这里没有鱼”等报错会记录为失败线索。不同钓鱼玩具或地区使用的施法名称可能不同，需要你在游戏里验收后补充识别规则。
- 游戏只在 `/reload`、退出或断线时把插件的 SavedVariables 写入磁盘。因此 exe 的“游戏记录”是**上次落盘的记录**，不是实时数据。成功率是按渔获事件的时间分组得到的估计值；它不等同于服务器提供的逐竿成功率，其他拾取行为也可能混入。
- 自动战斗仅在**游戏处于前台**且插件左上角的红/绿状态标记可见时有效。红色表示战斗，软件暂停钓鱼并每四秒发送一次战斗宏键。战斗结束后可按自定义“转向键”和时长转回水边；默认关闭转向。后台运行时，无法从 SavedVariables 实时获取战斗状态，所以不会执行盲目的战斗和转向操作。
- “喷泉降噪”在没有鱼漂声时录三秒环境声，进行简单频谱扣除。请在达拉然喷泉附近分别比较开启和关闭时的相似度；如果误报变多，关闭即可。现有核心匹配阈值保持旧版数值。
- “定时补盾”默认关闭；按需要勾选和设置间隔。长时间未检测到有效鱼漂声时会提示检查背景声音、输入设备及阈值。
- 某些游戏客户端可能不接受后台 `PostMessage` 按键；此时改用前台模式。后台模式能否工作需要在你的游戏环境中验证。

## 最短游戏验收

1. 检查声道识别、背景声音和鱼漂音量显示。
2. 用普通水域测试一次抛竿与收竿；观察阈值和误触发。
3. 在浅水处制造一次出杆失败，`/reload` 后按“同步记录”，检查失败记录。
4. 钓到一件物品后 `/reload`，检查物品与数量。
5. 若启用战斗宏，先在安全区域确认插件左上角状态标记能从绿色变红；再到烈毒之渊测试宏和转向时长。

## 从源码构建

Windows Python 3.9：`py -3.9 -m pip install -r requirements.txt`，然后执行 `build.ps1`。打包产物在 `dist/FishingHelper.exe`。运行时设置和降噪样本保存在 `%APPDATA%/FishingHelper/`。
